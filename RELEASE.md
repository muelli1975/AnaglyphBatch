# AnaglyphBatch 1.0

Create anaglyphs from SBS stereo images using 18 methods, with multiple-method selection and file/folder batch processing.

## Installation

Extract the complete portable Windows ZIP. Use `AnaglyphBatch_EN.bat` for English or `AnaglyphBatch_DE.bat` for German, and drag images or folders onto the batch file.

All required runtime tools are included, including the precompiled CIELab Anaglyph Tool. No compilation or additional installation is required.
