# AnaglyphBatch releases

The ready-to-use Windows release is distributed as a complete portable ZIP package via GitHub Releases.

It contains both German and English batch files and all third-party runtime tools required for normal use, including the precompiled CIELab Anaglyph Tool with its required OpenCV DLLs, FFmpeg, libjpeg-turbo (`cjpeg`) and ExifTool. No compilation or additional installation is required.

Download releases here:

https://github.com/muelli1975/AnaglyphBatch/releases

The normal repository intentionally keeps the large third-party binaries out of the source tree. Their expected layout and sources are documented in `TOOLS.md`; corresponding license texts and notices are included under `licenses`.

---

## Deutsch

Die fertige Windows-Version wird als vollständiges portables ZIP-Paket über GitHub Releases bereitgestellt.

Das Paket enthält die deutsche und englische Batch-Datei sowie alle für den normalen Betrieb benötigten Drittprogramme, einschließlich des fertig kompilierten CIELab Anaglyph Tools mit den benötigten OpenCV-DLLs, FFmpeg, libjpeg-turbo (`cjpeg`) und ExifTool. Es ist weder eine Kompilierung noch eine zusätzliche Installation erforderlich.

Downloads:

https://github.com/muelli1975/AnaglyphBatch/releases

Im normalen Repository bleiben die großen Drittanbieter-Binärdateien bewusst außerhalb des Source-Baums. Die erwartete Struktur und die Quellen sind in `TOOLS.md` dokumentiert; die zugehörigen Lizenztexte und Hinweise liegen unter `licenses`.
